API ​

The API serves the index. It turns a question into vectors, asks Qdrant for the nearest chunks, and returns them, or hands them to an LLM and returns its answer.

INFO

It is a FastAPI application served by uvicorn, started with python -m api.bin.

Multilingual retrieval ​

Retrieval works across languages thanks to two mechanisms:

  1. The embedding model is multilingual. Qwen3-Embedding-0.6B matches questions and passages with similar meanings, even in different languages.
  2. Query translation Marian model translate questions to bridge vocabulary gaps (e.g. « grappes » → clusters). The original query is always kept.

The LLM ​

/ask uses the official OpenAI Python SDK and the LLM_ENDPOINT variable, supporting any provider compatible with the Chat Completions API (Anthropic, OpenAI, Mistral or local Ollama).

Only three settings are needed: LLM_ENDPOINT, LLM_MODEL and LLM_API_KEY.
